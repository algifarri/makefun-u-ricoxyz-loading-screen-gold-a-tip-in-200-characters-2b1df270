A single loading-screen tip for stressed developers and AI coding agents, written to /output/entry.txt by a tiny deterministic Python program:

> Tip: the spinner isn't stuck — your agent is re-reading your function the way you re-read its diffs: slowly, twice, and already regretting it.

Why this tip: it lands in a glance (142 characters), and both sides of the keyboard feel seen — the developer waiting on the build and the agent re-reading the function are doing the same slow, regretful second read.

python3 main.py
